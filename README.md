# 潜水店充装调度台

周末出海前的气瓶充装/借用调度：管理 4 名持证潜水员、8 只气瓶，自动判定气体资质、
水压检测有效期、保留优先级和出发前释放。纯前端，数据只存在浏览器 localStorage。

## 运行

直接用浏览器打开 `index.html` 即可（无构建、无依赖）。
若浏览器对本地脚本有限制，也可起个静态服务：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 三个业务文件（判定 / 存取 / 页面）

| 文件 | 职责 | 不允许做的事 |
| --- | --- | --- |
| `rules.js` | 业务判定：水压超期、证内气体、保留时段、队列优先级、分配/领取/归还/释放/取消 | 不碰 DOM、不碰 localStorage |
| `storage.js` | 数据存取：预置 4 名潜水员与 8 只气瓶、localStorage 读写、恢复出厂 | 不含业务规则 |
| `app.js` | 页面：渲染、表单、筛选、模拟时钟、交互；所有判定调 `Rules`，所有落盘调 `StorageLayer` | 不直接写业务规则 |

另有 `index.html` / `styles.css` 两个表现层文件。

## 业务规则

1. **证内气体**：潜水员只能申请其证书列出的气体（AIR / EAN32 / EAN36 / TRIMIX / OXYGEN），否则直接驳回。
2. **水压检测五年**：上次检测满 5 年（到期日当天即算超期）的瓶一律退回 `inspection`；
   即使已被预占或在外借中，也会解除占用重新排队，外借瓶归还时若已超期直接进检修。
3. **保留优先**：类型为「出海前一天保留」的申请只能在出发前一天整日（00:00–24:00）提交，
   队列排序时整体排在普通借用之前；同类按提交时间先到先得。
4. **出发前 2 小时释放**：已分到瓶但未领取的保留申请，在 `出发时刻 − 2h` 起自动释放，
   气瓶回到可分配池供普通借用占用；已领取的瓶不受影响。
5. **匹配条件**：气体一致 + 瓶工作压力 ≥ 申请最低压力，同条件优先占用低工作压力瓶（高压瓶留给高需求）。
6. **列表筛选**：气瓶列表可按气体类型、工作压力下限筛选（筛选仅影响显示，不影响判定）。

## 演示方式

顶部有「模拟当前时间」（默认周五 09:00，处于保留窗口）和四个快捷时刻：

- 周四 10:00：保留时段未开启，提交保留会被拒绝；
- 周五 09:00：保留时段，保留申请优先；
- 周六 06:30：距出发 1.5 小时，未领取的保留瓶自动释放；
- 周六 09:00：出发后。

数据保存在 `localStorage` 的 `dive-dispatch-v1` 键下；底部按钮可一键恢复预置数据。
