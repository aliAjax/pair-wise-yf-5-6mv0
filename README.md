# 潜水气瓶充装调度台

潜水店周末出海气瓶分配工具：预置 **四名持证潜水员、八只气瓶**，在浏览器里完成
出海保留 / 普通借用的调度，数据保存在本地 localStorage，不上传服务器。

## 运行

直接用浏览器打开 `index.html` 即可，无需构建、无第三方依赖。
（`file://` 下若浏览器禁用 localStorage，会自动降级为内存态，刷新后回到预置数据。）

## 业务规则

- **证照限定气体**：每位潜水员只登记证内气体，证外气体提交即被拒绝。
  - 陈海峰：空气 / 高氧32
  - 林悦：空气 / 高氧32 / 高氧36
  - 王大涛：仅空气
  - 赵雪：全部五种气体
- **气瓶台账**：瓶号、气体类型（AIR / EAN32 / EAN36 / O2 / TRIMIX）、
  工作压力（bar）、上次水压检测日期、状态（在库 / 已保留 / 已借出 / 检修中）。
- **水压检测周期 5 年**：到期即自动退回检修，即使正在保留或借出中也收回；
  保留中的瓶被收回时，原保留请求回到队列排头。检修完成并登记新检测日才能回库。
- **优先级**：出海前一天的保留请求优先，普通借用排在其后；
  队列统一按「保留 → 借用、同类先到先得」排序，空瓶释放时自动补位。
- **保留到期释放**：出发前 2 小时仍未被领取的保留瓶自动释放，
  排队等待的普通借用立即接力；已点"领走出海"的瓶不受影响。
- **列表筛选**：按气体类型 + 工作压力区间筛选。
- 顶栏「时间与出发设置」可把系统时间拨到出发前 2 小时内，现场演示自动释放；
  「恢复预置数据」清空存档并重置为初始四名潜水员和八只气瓶。

## 文件结构（判定 / 存取 / 页面 三个业务文件）

| 文件 | 职责 | 依赖 |
| --- | --- | --- |
| `js/rules.js` | 纯业务判定：资质、水压、排队、释放、预置数据。无 DOM、无存储 | 无（UMD，可 Node 直接 require 测试） |
| `js/store.js` | localStorage 的读 / 写 / 清除，不可用时降级内存态 | 无 |
| `js/app.js` | DOM 渲染、事件、弹窗、提示；判定只调 rules，持久化只调 store | rules.js / store.js |
| `index.html` / `css/styles.css` | 页面骨架与样式 | — |
